The osu!catch Skill Rating

About

The Skill Rating Project's goal is to use what readily available information we can get our hands on and adapt it into an osu!skills form of Skill Breakdown so that the Average Player can better spot their strengths and weaknesses.
In comparison to the Performance System baked into osu!, our rough Multi-Skill System displays Six Different Skills with which we have basic things in place to do as well of a job at Estimating player proficiency at each skill.

How?

All of the following skills are balanced with community feedback into a single value.It's not always going to be accurate as we do not have all the tools neccesary to make this from scratch.

  • RFX: (Reflexes)
      Approach Rate Data taken from Top 100 Scores on profile (by pp), Weighted by Descending AR, Calculated based on Exponential Curve
  • TEN: (Tenacity)
      Calculated by Profile Performance (50%) and Profile Map Difficulty (50%, Weighted by Descending Map Difficulty) based on Exponential Curve
  • STA: (Stamina)
      Performance Data and Mod-Adjusted Map Length Data taken from Top 100 Scores (by pp), Calculated by Exponential Curve with added weight to Tenacity (50%)
  • ACC: (Accuracy)
      Mixture of Profile Accuracy (60%) and Tenacity (40%)
  • REA: (Reading)
      Human Quantified Estimation of any Convert / EZ-Mod / Low-AR / HD-Mod scores
  • PRE: (Precision)
      Performance Data and Circle Size Data taken from Top 100 Scores (by pp), Calculated by Exponential Curve weighted by Circle Size (50%) and Tenacity (50%)
